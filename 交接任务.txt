四、EdgeOne 运行时硬性约束
------------------------

1. EdgeOne Pages 不执行 PHP，不能把 .php 原样部署。
2. 已采用 node-functions/[[default]].js，运行在 EdgeOne Node 云函数。
3. edgeone.json 中 Node 版本必须用 22.21.1。20.19.0 在 EdgeOne CI 中已实测切换失败。
4. 构建配置：
   - installCommand: npm install
   - buildCommand: npm run build
   - outputDirectory: dist
5. Pages Blob SDK 在 EdgeOne 运行时自动获得项目凭据；本地直接调用真实 Blob 会报 Missing deployCredential，这属于预期。
6. Node Cloud Functions 请求体限制约 6 MB，所以图片限制为 4 MB，为 multipart 预留空间。
7. 不要将 PHP Session、mysqli、PHP 文件写入或本地 uploads/ 目录带到新运行时。
8. 不要用 Edge Functions 的 200ms CPU 运行所有业务；继续使用 Node Functions。
9. 存储应继续使用 @edgeone/pages-blob，参考仓库：
   /home/fanxing/下载/OpenList-Worker

七、数据模型建议
----------------

可继续用一个强一致 JSON 主文档 likegirl_site_data，但要完整扩展为：

{
  site: {
    title, logo, writing, background, icp, copyright,
    boy, girl, boyQQ, girlQQ, startTime,
    animation, blur,
    card1, card2, card3, deci1, deci2, deci3
  },
  about: {
    title, background,
    info1, info2, info3, btn1, btn2,
    infox1...infox6, btnx2,
    infof1...infof4, btnf3,
    infod1...infod5
  },
  messageSettings: {
    displayLimit, blockedCharacters, blockedWords
  },
  blockedIps: [
    { id, ip, note, createdAt }
  ],
  accessWarnings: [
    { id, ip, location, path, createdAt }
  ],
  stories: [
    { id, title, author, date, content }
  ],
  photos: [
    { id, date, text, urls: [] }
  ],
  wishes: [
    { id, text, image, done }
  ],
  messages: [
    { id, name, qq, text, ip, city, createdAt }
  ]
}

注意：
- 公开 /api/data 不能暴露留言 IP、封禁列表、访问记录等管理数据。
- /api/admin/data 必须验证 Bearer Token 后才返回完整数据。
- 所有管理写入必须在服务端验证类型、长度、数量和 URL。
- 图片 Blob key 继续使用 image_<uuid>.<ext>。
- 删除/替换数据后清理无引用图片，但不能删外部 URL。
- Blob 存储不是事务数据库；写入时尽量整体校验后单次保存。

八、当前 API（可复用但需扩展）
--------------------------------

GET  /api/health          Blob 健康检查
GET  /api/data            公开站点数据
POST /api/messages        提交留言

GET  /api/admin/data      获取完整管理数据
PUT  /api/admin/data      更新管理数据

GET  /api/media/:key      读取图片 Blob

十二、安全和许可注意事项
--------------------------

- 无需认证环境变量：首次访问 /admin.html 自动进入 /init.html 设置密码。
- 不得把真实密码/密钥写入仓库。
- 原版 Config_DB.php 中是旧默认值，EdgeOne 版不得使用它。
- 不能恢复 MD5 密码存储。
- 不能直接信任 X-Forwarded-For 作为安全边界；优先使用 EdgeOne context.clientIp/平台头。
- 不能将 IP、QQ、封禁列表通过公开 API 返回。
- 用户内容必须转义；如保留文章 HTML，必须用可审计的标签/属性白名单。
- LICENSE 是完整、未修改的 GNU AGPL-3.0 正文。
- package.json 中已标注 AGPL-3.0-only。
- NOTICE 说明了 Ki.、ShiFengShuA 和 EdgeOne 适配层的来源。
- 不要移除上游源文件中的署名和版权声明。
